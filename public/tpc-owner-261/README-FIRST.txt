THEPAGECRAFT OWNER CONTROL CENTER v8

- Supabase URL and public publishable key are already configured.
- Username is permanently fixed to meritesharma.
- Login asks only for your password.
- Your password is NOT stored in these files. Supabase verifies it securely.
- The owner session automatically locks after 5 minutes of inactivity.
- UI is matched to ThePageCraft dark/gold/violet design system.
- Coupons & Offers controls percentage/fixed discounts, limits and schedules.
- Customers & Profiles opens the complete editable customer profile.
- Promotions & Alerts sends popup posters, notifications and coupons.

Run RUN_THIS_V8_COUPONS_CAMPAIGNS.sql from the project root in Supabase SQL Editor before opening v8 tools.

Open index.html when testing locally, or deploy the folder as a static site.
